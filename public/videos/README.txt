Place your hero.mp4 video file in this folder.
The VideoHero component will auto-detect and use it.
If no video is found, the site falls back to the image slideshow.

Recommended specs:
  - Format: MP4 (H.264)
  - Resolution: 1920x1080 or higher
  - Duration: 15-30 seconds (looping)
  - File size: under 15MB for fast loading
